__Как запустить__  
1. Клонировать репозиторий:  
```  
git clone <url>  
```  
2. Перейти в папку:  
```  
cd lab2_todo  
```  
3. Установить зависимости:  
```  
dart pub get  
```  
4. Запустить:  
```  
dart run  
```

__Ответы на вопросы:__  
1. Поле класса принадлежит объекту и живёт, пока живёт объект. Переменная в функции существует только во время её выполнения и недоступна извне.
2. Конструктор - специальный метод, вызываемый при создании объекта. Нужен для инициализации полей, чтобы объект сразу был в корректном состоянии.
3. @override говорит компилятору, что метод переопределяет метод родителя, и защищает от опечаток в имени. Если убрать - код будет работать, но компилятор не проверит, что это действительно переопределение.
4. Статическое поле принадлежит классу целиком, а не объектам. Существует ровно одна копия в программе, независимо от числа созданных объектов.
5. _ делает идентификатор приватным для файла: обратиться к _counter из другого файла нельзя.
